# 工作台视觉主题

工作台提供五套配色，默认保留青色主题。每套配色共用布局、字号和交互，通过主要按钮、品牌区、页面底色和选中层次体现区别。录音与转录进度沿用暖橙，错误和成功状态也保持共同含义。

从侧栏「外观配色」选择后立即生效。本机浏览器保存选择，刷新后恢复；同源页面之间同步。选择器支持方向键切换、Escape 关闭并返回入口。偏好存储不可用时仍可在当前页面换色。

所有应用配色和阴影统一定义在 `src/theme.css`。`src/styles.css` 负责布局、字号、间距和交互状态，通过 CSS 变量引用颜色。修改主题时，先调整主题文件中的语义变量；无需逐个修改组件。

## 默认品牌色

下表按 HSB 转为 sRGB，再四舍五入至 8 位 RGB。浅青的精确结果是 `#CEEFF0`。

| 色彩 | HSB | RGB | 变量 | 用途 |
|---|---|---|---|---|
| 浅青 | H 182° / S 14% / B 94% | `#CEEFF0` | `--brand-light` | 选中底色与轻量品牌背景的基色 |
| 标准青 | H 182° / S 97% / B 71% | `#05AFB5` | `--brand` | 页签标记、选中边线、拖动反馈 |
| 深青 | H 182° / S 97% / B 50% | `#047B80` | `--brand-deep` | 引用、链接、焦点、主题图标 |
| 深蓝 | H 205° / S 56% / B 31% | `#233D4F` | `--brand-blue` | 主要行动、品牌标识和重要标题 |

标准青与白色的对比度约为 2.69:1，因此不作为小字号白字按钮的底色。主要按钮采用深蓝底与白字；选中背景由浅青与白色混合，文字保留深青或深灰。

## 可切换配色

实际主题由根元素的 `data-theme` 控制。`cyan` 使用默认变量，其余四种通过 `:root[data-theme="…"]` 覆盖语义变量。切换不改变会议内容和面板布局。

| 标识 | 原始参考色 | 在工作台中的使用 |
|---|---|---|
| `cyan` | `#CEEFF0`、`#05AFB5`、`#047B80`、`#233D4F` | 原有青色主题；深蓝按钮，浅青选中，深青引用 |
| `deep-sea` | `#122E8A`、`#F5EFEA` | 原深海蓝用于主要按钮与品牌标识，原柔奶白用于页面背景，蓝白衍生色用于选中与引用底色 |
| `lagoon` | `#2DACB5`、`#C3E9EA`、`#1E2D58`、`#374D73` | 原青色按钮配原深蓝文字，原浅青用于选中；两种深蓝分别用于正文、标题和次级说明 |
| `sky` | `#2F9CFF`、`#FFE632` | 原晴空蓝用于主要按钮与页签，原亮黄用于品牌标识文字；浅黄衍生色用于选中和澄清卡片 |
| `iris` | `#A75EFF`、`#FFFF81` | 原鸢尾紫用于主要按钮与页签，原浅黄用于品牌标识文字；淡黄选中层次配深紫标题和引用 |

参考图的明亮颜色不直接承担所有文字角色。青瓷、晴空和鸢尾的主要按钮保留原色，按钮文字改用深色，避免小字号白字不清楚；悬停时略提亮底色。引用、键盘焦点和小字链接使用同色系深色衍生值，亮黄和浅黄表面始终搭配深色文字。

`--palette-1` 至 `--palette-4` 仅保存选择器色块的原始参考色，不作为组件语义色的别名。每个预览使用 `.theme-preview[data-palette="标识"]` 获得自己的四个色块，避免继承当前主题而让所有选项显示相同颜色。只有两种原色的方案重复两次显示，未添加虚构的参考色。

### 新主题的对比检查

下表使用实际语义变量计算，覆盖按钮文字、页面辅助文字、选中内容和链接。原色之外的深色衍生值是为保持可读性而选定的；它们也集中保存在 `src/theme.css`。

| 主题 | 按钮文字 / 按钮底色 | 辅助文字 / 页面底色 | 辅助文字 / 选中背景 | 链接 / 选中背景 |
|---|---:|---:|---:|---:|
| `cyan` | 11.34:1 | 4.81:1 | 4.68:1 | 4.59:1 |
| `deep-sea` | 11.77:1 | 4.96:1 | 4.71:1 | 9.81:1 |
| `lagoon` | 4.89:1 | 5.58:1 | 4.62:1 | 4.54:1 |
| `sky` | 5.14:1 | 5.41:1 | 5.07:1 | 5.72:1 |
| `iris` | 4.69:1 | 6.03:1 | 6.18:1 | 8.18:1 |

各主题的主要按钮悬停状态也保留至少 4.5:1 的文字对比。这些数值针对表中指定颜色组合，不等同于整页可访问性认证。

## 语义变量

| 变量组 | 作用 |
|---|---|
| `--canvas`、`--surface`、`--surface-muted` | 页面、面板和次级表面 |
| `--ink`、`--ink-secondary`、`--ink-muted` | 正文、补充说明和辅助文字 |
| `--border`、`--border-strong` | 面板分隔与表单轮廓 |
| `--brand-tint`、`--brand-selected`、`--brand-border` | 轻量强调、选中和引用边框 |
| `--action`、`--action-hover`、`--action-text` | 主要按钮及悬停状态 |
| `--focus`、`--focus-halo` | 键盘焦点与输入框焦点 |
| `--progress`、`--progress-track` | 录音状态点及上传、转录进度 |
| `--warning-*`、`--error-*`、`--success-*`、`--info-*` | 提醒、失败、已完成和说明信息 |
| `--map-*`、`--xy-*` | 导图节点、连线、网格与 React Flow 控件 |
| `--shadow-*`、`--backdrop` | 面板、浮层、弹窗阴影及遮罩 |
| `--palette-1` 至 `--palette-4` | 主题选择器显示的原始参考色 |

状态始终同时使用文字或图标表达，不要求参会者仅凭颜色区分结果。导图使用 React Flow 的公开 `--xy-*` 变量，避免其按需加载的默认样式覆盖主题颜色。

## 字号与对比度

正文采用 14px，较紧凑的问答和进展正文采用 13px，辅助信息采用 12px。移动端保留可读字号，以换行、滚动和纵向布局适配宽度；表单输入采用 16px。

以下为默认青色主题根据 sRGB 相对亮度计算的对比度，数值取两位小数。它们是指定颜色组合的检查结果，不代表整页已经通过完整可访问性认证。

| 组合 | 对比度 |
|---|---:|
| 正文 `--ink` / 白色面板 | 12.78:1 |
| 次级正文 `--ink-secondary` / 白色面板 | 6.44:1 |
| 辅助文字 `--ink-muted` / 白色面板 | 5.17:1 |
| 辅助文字 `--ink-muted` / 灰白页面 | 4.81:1 |
| 辅助文字 `--ink-muted` / 选中背景 | 4.68:1 |
| 深青 / 白色面板 | 5.06:1 |
| 深青 / 选中背景 | 4.59:1 |
| 白字 / 深蓝主要按钮 | 11.34:1 |
| 暖橙进度 / 进度轨道 | 3.08:1 |

字号和颜色均可在对应文件中核对。应用样式未保留 8–11px 的辅助字，也未在主题文件之外硬编码颜色值。

## 布局与动效

桌面以连续阅读面承载澄清焦点与讨论脉络；转录、讨论进展和问答按需打开浮窗。主内容通过字号、行宽与留白区分层次，较矮窗口允许讨论内容独立滚动，底部工具入口保持可见。

800px 以下减少边距并调整标题与操作的排列。导图、转录原文、长纪要和处理记录在各自区域内滚动。可滚动内容预留滚动条空间，减少更新时的横向跳动。

悬停、焦点和进度变化使用短时过渡；忙碌状态保留旋转和录音状态点。弹窗由组件使用 Web Animations API 控制，样式表不叠加重复的弹窗动画。`prefers-reduced-motion` 会关闭非必要过渡和循环动画。

较长的转录和问答使用 `content-visibility` 减少离屏绘制。当前引用原文和获得焦点的条目保持正常渲染，便于定位和键盘操作。

阅读面与悬浮控件的颜色由 `--reading-surface`、`--navigation-surface`、`--control-material`、`--floating-edge`、`--soft-divider` 和对应阴影变量配置，五套主题共用语义映射。正文使用实色；入口可使用低透明度材质，减少透明度设置下回退实色。
