# 交互与视觉打磨

会议中的共同阅读围绕当前需要说清什么、原话在哪里、讨论取得了什么进展。记录可以是中性的讨论记录、部分进展或已明确的结果；有记录不等于问题已经解决。

## 技术选择

2026-09-08 核对官方文档和 npm 发布时间，选用截至 2026 年 8 月 31 日已有的稳定版本。版本在 package.json 中固定：React / React DOM 19.2.8、Vite 8.2.2、React 插件 6.1.1、React Compiler 1.0.0。编译器使用官方 Babel 接入方式，桥接插件为 @rolldown/plugin-babel 0.2.3，Babel 7.29.7。

- 浮窗保持组件挂载，以 hidden / inert 收起，保留输入和滚动位置并退出键盘导航；收起时暂停音频。后台会议刷新用 startTransition 降低更新优先级，录音控制继续立即响应。[React 19.2](https://react.dev/blog/2025/10/01/react-19-2)
- React Compiler 自动优化可分析的组件，遇到不支持的代码结构会保守跳过。长内容组件另有稳定属性与 memo 边界，避免面板拖拽牵动整段转录重绘；不为通过编译而重写录音时序。[Compiler 1.0](https://react.dev/blog/2025/10/07/react-compiler-1)、[官方 Vite 接入](https://react.dev/learn/react-compiler/installation)
- Vite 8 负责开发与构建，讨论脉络及导图按需加载，减少打开工作台时的首次下载。[Vite 8](https://vite.dev/blog/announcing-vite8)
- 弹窗保留原生 dialog 的焦点约束，使用 Web Animations API 做短开场动效，关闭与保存立即响应。按钮和切换使用原生 CSS，尊重减少动态效果设置；拖动通过 requestAnimationFrame 合并每帧更新。

## 操作细节

会中主页面采用连续阅读面，保留「澄清焦点／讨论脉络」切换。焦点默认显示一个推荐问题、一段讨论价值，以及依据和记录操作。完整问题、解释、影响、分类、版本与主题在「查看依据」中展开，其他问题按需展开。

主屏默认跟随当前推荐。推荐问题已完成或被主持人「先放下」后，即使下一次分析尚未开始，也会优先接着显示同主题的有效问题；AI 明确没有推荐时保持安静，不用旧问题填满页面。过期或已合并的问题不作为独立焦点。

主动选择其他问题或展开依据后，页面保留阅读位置，点击「回到当前」恢复跟随。编辑期间暂停切换，关闭编辑后恢复此前的跟随状态；原本主动停留的页面仍停留。部分回答显示为「已说清的部分」，原问题继续反映尚未解除的核心疑问，不因 AI 将部分进展归为 `clarified` 就退出讨论。

会议标题旁的「会议操作」收纳纪要、重新分析、自动整理、处理记录和设置；会中的录音控制与异常直接可见。导航、菜单入口和底部工具使用轻微浮起的表面，正文保持不透明；不支持模糊或启用减少透明度时使用实色。

「记下讨论结果」在问题下面展开输入框，活跃问题默认保存 `recorded` 状态的讨论记录，不等于形成共识或问题已解决。默认选项是「先记下来」；「补充说明（可选）」中可选择「已经说清楚」「还需要验证」「还有不同意见」，并附上原话。编辑已有结果时保留原类型。「已经说清楚」表示含糊的地方得到了解释，不代表所有人都同意。

讨论脉络按持续演进的事项呈现。同一事项的补充、回答和修订沿用条目，过程保留在历史。主题详情默认展示五条以内的当前内容，决定和行动项全部可见，因此较多时可以超过五条；其余当前条目按需展开。已回答的问题、被替代或待复核的条目，以及概述旧版本收在「讨论过程」中，可展开查看来源。当前概述也保留原文依据。

原文、讨论进展与问答从底部入口打开非模态浮窗，收起后继续读原来的讨论。不会因新转录或新回答自动打开浮窗。原文引用直接切到对应片段，播放器与搜索共存；说话人可逐段标记，补录遗漏发言收到「更多」中。

浮窗每次只打开一个，切换保留各自草稿和滚动位置。Escape 优先关闭编辑对话框，再关闭菜单或浮窗，最后退出展示模式；收起浮窗回到打开它的入口。侧栏宽度在停止调整后保存到本机，分隔条支持方向键及 Home / End。讨论标签支持左右键切换，大纲和导图保留选中主题。

录音导入既可选择文件，也可拖放。更换文件保留手工填写的会议名称；无效替换保留之前有效的选择，错误在当前表单中说明。上传期间继续使用真实进度和离开页面提示，不提前报告转录完成。

全局颜色独立放在 [src/theme.css](../src/theme.css)，颜色角色见 [THEME.md](THEME.md)。文字、边框、阴影、图节点、状态和进度都通过语义变量引用。

## 验收

使用独立的 `test-output/visual-qa/` 模拟会议核对桌面与窄屏布局、弹窗焦点、浮窗切换、键盘操作、长转录滚动、引用回听和导图。正式会议仅用于查看实际长内容的布局。模拟材料不写入正式会议库，也不代表真实模型输出。最终结果另记入 [验收记录](VALIDATION.md)。
