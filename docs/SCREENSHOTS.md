## 复现截图

```sh
npm ci
npm run build
npm run demo
```

打开终端输出的地址，默认端口为 `8798`。脚本位于 [`scripts/demo.mjs`](../scripts/demo.mjs)。每次运行创建独立的系统临时目录，不加载 `.env`，不读取正式 `WORKBENCH_DATA_DIR`，并清空当前演示进程中的模型与 ASR 环境配置。预置会议关闭自动分析，无音频和声音样本；查看时不调用模型。

1. 在「外观配色」中选择「经典青」。
2. 打开「复盘焦点」，查看报名表的两种「稳定」含义。
3. 切到「讨论脉络」，选择「报名表与信息更新」，切换到导图。
4. 打开「录音与原文」，搜索「联系」，查看高亮结果。
5. 在「会议操作 → 会议纪要」查看预置纪要。

按 `Ctrl+C` 停止演示。临时目录路径会打印在终端，停止后可以将其移入废纸篓。再次运行会创建一份新演示，不保留之前的操作。正式会议请使用 `npm start`，按上手指南连接自己的服务。
