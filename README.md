# 会议工作台

供主持人在本机使用的会议辅助工具，面向产品和技术方案讨论。围绕当前要作出的选择，帮助参会者发现尚未对齐的概念、隐含前提和取舍标准，并记录讨论进展。其他参会者通过投屏或共享窗口观看。

## 启动

安装 Node.js 22.13 或更新版本，在项目目录执行：

```sh
npm ci
npm run build
npm start
```

打开 [会议工作台](http://127.0.0.1:8797)。没有模型密钥也能打开界面、创建会议；转录和 AI 分析需要分别配置服务。导入录音还需要安装 `ffmpeg`。

首次使用请看 [上手指南](docs/GETTING_STARTED.md)，包含 macOS / Windows 启动步骤、服务配置、Agent 接入和常见问题。

## 使用方式

- **开始会议或导入录音**：实时录音保存在本机；已有录音可分段转录，不需要麦克风授权。
- **围绕一个问题讨论**：主画面突出当前澄清焦点，解释和原文引用按需展开。讨论后可以就地记下一句话，保存记录不代表问题已解决或形成共识。
- **需要依据时再查看**：底部的「录音与原文」「讨论进展」「问 AI」按需打开。原文支持搜索、标记说话人和定位回听；问答依据本次会议转录。
- **会后整理**：在右上角「会议操作」中打开会议纪要，也可以重新分析、查看处理记录或归档会议。归档可以恢复。

自动整理每 30 秒检查新增定稿转录，没有新增内容时不调用模型。人工修正会保留；相关原文变化后，受影响的 AI 内容会标记为待核对。

## 当前范围

第一版面向本机、单主持人、中文会议，服务只接受本机访问。实时 ASR、文件 ASR 和大模型独立配置，不随项目附带模型或账户。

导图目前展示主题及其父子关系，观点、问题、决定和行动项放在主题详情中。并列主题会显示为独立节点；尚未自动展示跨主题的前提依赖或因果关联。概念澄清、隐含假设与决定识别仍需对照原话核对。

会议、设置与密钥保存在本机 `data/` 中。使用远程 ASR 时音频会发给所配置的识别服务，使用远程大模型时相关转录会发给所配置的模型服务。向同事分发程序时使用源码包，保留各自的 `data/` 和 `.env`，不要把它们作为程序文件一起发送。

## Agent 与开发

项目提供 stdio MCP 服务和 `meeting-workbench` Skill，页面与 Agent 共用同一套业务 API。接入步骤见 [Agent 接入](docs/GETTING_STARTED.md#agent-接入)。

开发模式：

```sh
npm run dev
```

网页使用 `http://127.0.0.1:5187`，API / MCP 使用 `http://127.0.0.1:8797`。运行前先停止占用相同端口的本项目服务。

本地检查：

```sh
npm run release:check
```

检查包含服务端语法、自动测试和前端构建。自动测试使用模拟 ASR / LLM，不消耗外部模型额度；识别准确率和真实会议效果需要另行试用。
